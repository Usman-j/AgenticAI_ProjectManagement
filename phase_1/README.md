# Phase 1: Agent Toolkit

Phase 1 contains a reusable set of agent classes and standalone scripts that demonstrate their behavior. The classes are defined in `workflow_agents/base_agents.py` and cover direct and persona-guided prompting, supplied-knowledge prompting, retrieval-augmented generation, response evaluation, semantic routing, and action planning.

## Contents

- `workflow_agents/base_agents.py` — agent class implementations.
- `workflow_agents/__init__.py` — package marker.
- The top-level `*_agent.py` files — standalone agent examples.

The Phase 1 examples use this directory’s `workflow_agents` package. Setup and environment configuration are documented in the [main README](../README.md).
